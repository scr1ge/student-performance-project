# Анализ успеваемости студентов — практическая работа 2

Подготовка данных, предметный EDA и проектирование системы по методичке.
Модели не обучаются: это задача практической работы 3.

## Данные

Источник: https://www.kaggle.com/datasets/lainguyn123/student-performance-factors
Локальный источник: StudentPerformanceFactors.csv, 6607 строк и 20 столбцов.
SHA-256: e8df8c4148ef83fb295ca1c092f2c6ee15272c0a8e3018b769a788ab50e96e97

- data/raw/StudentPerformanceFactors.csv — неизменяемый исходник;
- data/base/base.csv — исходная часть, 3964 строки;
- data/incoming/batch_01.csv ... batch_04.csv — 661, 661, 661, 660 строк;
- data/manifests/split_manifest.json — версии, хеши и исходные индексы строк.

Временных полей нет. Разбиение случайное, seed=42; incoming не используется для EDA.
Порции имитируют новые выгрузки; это не реальные последовательные семестры.
При реальном прогнозировании Exam_Score неизвестен и исключается из X.
В учебных порциях метки уже есть только потому, что воспроизводится исторический набор.

## Запуск в PowerShell

Рекомендуется Python 3.12. Зафиксированные зависимости рассчитаны на эту версию.

```powershell
cd "D:\UNIVERSITY_STUFF\5course\ТИМО\student-performance-project"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\run_eda.py
```

После установки зависимостей EDA воспроизводится последней командой.
Активация venv и изменение ExecutionPolicy не требуются.
Для notebook в VS Code при необходимости установить requirements-notebook.txt
тем же интерпретатором и выбрать его как kernel. Сохраненные результаты доступны
в notebooks/2practice.ipynb без повторного выполнения.

## Проверенные результаты

EDA выполняется на 3964 строках. Найдены 49/53/42 пропуска в трех категориальных
полях и одна оценка 101. После исключения неверной метки в анализе связей 3963 строки.
Дубликатов нет. Условный риск — балл ниже 65: 842 записи (21,247%). Это учебный
порог, а не норматив университета. Проверены четыре гипотезы с поправкой Бонферрони.

Статистические выбросы не удаляются автоматически. Недопустимая целевая метка
не заменяется на 100. Исходный CSV не изменяется.
